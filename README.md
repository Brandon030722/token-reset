## 免费查看重置线索

无需邀请码，即可查看当前重置信号、最近检查结果、相关动态和原帖。

约每 **15 分钟**检查一次公开动态。没有足够依据时不强行给出预测，历史动态与当前信号分开展示。

## 有消息，发一封邮件

邮件提醒采用邀请制。填写邮箱和邀请码，完成邮箱确认后，由 **Token重置统一发信**，无需自己配置邮件服务。

广泛重置信号评分达到 **80 分**时发送提醒，同一事件避免重复打扰。可以随时退订，电脑关机也不影响云端检查和公共邮件发送。

邀请码请向邀请人获取，公开仓库不附带有效邀请码。

## 配合桌面应用使用

[Token重置桌面版](https://github.com/Brandon030722/token-reset-desktop)提供 Mac（Apple 芯片）和 Windows x64 下载。**T!** 图标常驻 Mac 菜单栏或 Windows 任务栏托盘，关闭面板后仍继续监控。

- 查看公开重置动态，接收本机系统通知。
- 小范围重置和补偿公告单独提醒，并标明适用范围。
- 查看本机 Codex 每周剩余额度和下一次恢复时间。
- 确认邀请订阅后，可单独开启个人周邮件。
- 已同步的个人预约在关机、休眠时仍可由云端发信。

个人每周提醒只发给本人，不向公共订阅者群发。下一周期需要本机重新读取新的恢复时间。

## 提醒意味着什么

**80 分是信号强度评分，不代表重置有 80% 的发生概率。** 公开动态可能遗漏或延迟；到点邮件表示先前记录的恢复时间已到，不保证额度已经到账。请以 Codex 实际显示为准。

本机通知需要应用运行并获得通知权限；已同步的云端预约不依赖电脑持续开机。关闭预约和退订需要联网完成，已发出的邮件无法撤回。
